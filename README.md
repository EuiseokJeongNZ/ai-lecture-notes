## 4. Day Folder Rule

각 Day 폴더는 아래 규칙을 따릅니다.

```text
DayN/
├─ Lecture_Materials/
├─ README_AI_N차시_정리.md
└─ Summary_DayN.ipynb
```

| 파일 / 폴더 | 역할 |
|---|---|
| `Lecture_Materials/` | 강의 PDF, 원본 ipynb, srt 자막 등 원본 자료 |
| `README_AI_N차시_정리.md` | 강의 개념, 코드 흐름, 주요 함수/변수, 시험용 요약 정리 |
| `Summary_DayN.ipynb` | Markdown 셀과 Code 셀을 분리한 실행 가능한 요약 노트북 |

---

## 5. Study Flow

추천 학습 순서는 다음과 같습니다.

1. `Lecture_Materials/`에서 원본 강의자료 확인
2. `README_AI_N차시_정리.md`로 개념과 코드 흐름 복습
3. `Summary_DayN.ipynb`를 실행하면서 코드 동작 확인
4. 주요 변수, 함수, 출력 결과를 다시 정리
5. 시험용 요약으로 마지막 복습
